# ch06 前置代码阅读指南

> 面向几乎没有 Python 基础的读者。本指南的目标不是让你一次读懂所有代码，而是先建立 ArtCode 工具执行主流程的整体印象，为 ch06 权限系统做准备。

## 一、先记住这一条主线

```text
用户输入
  ↓
Runtime 创建 AgentRunRequest
  ↓
AgentLoop 请求模型
  ↓
模型返回文字或工具调用
  ↓
ToolBatchExecutor 检查、分组并执行工具
  ↓
工具使用 ToolExecutionContext 校验路径、超时等边界
  ↓
工具结果写回 Conversation Context
  ↓
模型根据结果继续行动或给出最终回复
  ↓
TUI 展示过程
```

现在不需要记住所有类名。只要先理解：`AgentLoop` 是总导演，`ToolBatchExecutor` 是工具调度员，具体 Tool 是执行者，TUI 是显示器。

## 三、第一遍可以跳过的内容

第一遍阅读时，可以暂时跳过：

- 文件顶部的大部分 `import`。
- 所有类型标注的精确含义。
- 错误处理的每个分支。
- Event 对象的每一个字段。
- Prompt Cache 和 Token Usage。
- 以单下划线开头的辅助方法的内部细节。

第一遍只回答三个问题：

1. 这个文件负责什么？
2. 谁调用它？
3. 它处理完以后把结果交给谁？

## 四、阅读 Python 代码的通用方法

看到一个类时，按下面顺序阅读：

1. 先看类名和它保存的字段。
2. 再看 `__init__` 或 `__post_init__`，了解对象创建时准备了什么。
3. 找没有下划线开头的主要方法。
4. 最后再看 `_xxx` 私有辅助方法。

看到一个函数时，按下面顺序阅读：

1. 看函数名，猜它要完成什么。
2. 看参数，确认它需要什么材料。
3. 看 `return` 或 `yield`，确认它交出了什么结果。
4. 最后再看中间的判断和循环。

## 五、ch06 会重点改造的连接点

当前代码已经具备权限系统的若干零件：

- 工具分为只读和有副作用两类。
- Agent Mode 可以限制工具名称。
- 工具执行前有 `prepare` 阶段。
- `PreparedToolCall` 包含操作预览。
- `ToolPreview` 包含 `requires_confirmation`。
- TUI 已经有确认方法。
- 文件路径已经受允许目录限制。

但这些零件还没有串成统一的审批流程。当前 `ToolBatchExecutor` 在工具准备成功后会直接执行，没有把预览交给用户确认。ch06 的核心，就是在“准备完成”和“真正执行”之间加入权限决策。

## 六、你读完后的最低目标

不要求能默写代码。只要能够用自己的话回答以下问题，就算达到目标：

- `AgentLoop` 为什么要循环？
- 模型请求工具后，谁负责执行？
- 为什么工具要先 `prepare` 再 `execute`？
- 允许目录和用户确认有什么区别？
- TUI 为什么不应该直接决定权限规则？
