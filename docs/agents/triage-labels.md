# Triage Labels

Matt skills 使用五个固定角色。本仓库直接使用同名 GitHub 标签。

| Matt role | GitHub label | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已明确，可由 Agent 独立执行 |
| `ready-for-human` | `ready-for-human` | 需要人类亲自处理 |
| `wontfix` | `wontfix` | 已决定不处理 |

Skill 提到某个 triage role 时，使用本表对应的 GitHub label。
