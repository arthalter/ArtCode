# Domain Docs

本仓库使用单一 Context。

## 探索前按需读取

- 根目录 `CONTEXT.md`：ArtCode 领域语言的权威词汇表。
- `docs/adr/`：与当前工作相关的架构决策。

文件尚未存在时直接继续，不因缺失阻断工作。`domain-modeling` 在语义或决策真正确定时按需创建它们。

## 词汇约束

- Issue 标题、Spec、票据、实现和验收统一使用 `CONTEXT.md` 中的术语。
- 不为同一概念引入新同义词。
- 需要的词汇不存在时，先判断它是新领域概念还是可删除的实现语言；只有前者进入 `CONTEXT.md`。

## ADR 冲突

新方案与已有 ADR 冲突时，先显式指出冲突并重新决策，不静默覆盖。
