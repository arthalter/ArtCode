## Token 近似估算

- [x] 汉字按 `1 字符 = 1 Token`，其他 Unicode 字符按 `3 字符 = 1 Token`，两部分分别计数并向上取整。（验证：用纯中文、纯英文、代码和混合文本运行估算器测试。）
- [x] 没有 API usage 锚点时，可以从完整的已组装请求得到稳定估算值。（验证：对相同消息和工具 Schema 连续估算两次，结果一致。）
- [x] 有锚点时使用“上次真实 prompt_tokens + 当前字符估算 − 锚点字符估算”，且结果不会小于零。（验证：分别增加和删除消息，检查正负增量。）
- [x] 估算内容包含 System Prompt、对话消息、System Reminder 和本轮实际发送的工具 Schema。（验证：逐项加入内容，观察估算值增加。）
- [x] 只有普通会话请求的 `prompt_tokens` 更新锚点，内部摘要请求 usage 不覆盖锚点。（验证：在普通请求之间插入摘要请求，检查锚点仍对应上一普通请求。）
